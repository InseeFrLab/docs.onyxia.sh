# Community calls

Our community calls take place **on the last Thursday of each month at 16:30 (Paris time)**.

{% file src="../../.gitbook/assets/onyxia-call.ics" %}

These calls are open to **everyone** — a great opportunity to:

* Get the latest project updates &#x20;
* Ask questions
* Discuss the roadmap
* Showcase how you're using the project<br>

To join, simply head over to our Slack workspace and join the [_#community-meeting_](https://3innovation.slack.com/archives/C0664UVJ77W) channel.
